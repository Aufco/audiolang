# AudioLang

Minecraft Forge 1.21.4 language-learning mod published from this repository.
The mod source is under `src/`; generated Gradle and build output is excluded.

See [BUILD_GUIDE.md](BUILD_GUIDE.md) for the Forge MDK setup, development run,
and JAR build process. Java 21 and Forge 1.21.4 MDK 54.1.0 are required.
